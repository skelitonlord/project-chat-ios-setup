Project Chat setup

This page prepares the public trust certificate for your private Ubuntu companion.

Reading the setup QR…

Compare this SHA-256 fingerprint with the one in Project Chat on Ubuntu before trusting the certificate.

Download profile
  1. In Safari, allow the profile download. In Settings, open Profile Downloaded and install Project Chat Companion Trust.
  2. Open Settings → General → About → Certificate Trust Settings. Enable full trust for the Project Chat companion CA.
  3. Return to Project Chat on Ubuntu and use the separate Pair device QR.
  1. Compare the fingerprint and download project-chat-companion-ca.cer.
  2. In Android Settings, search for Install a certificate, choose CA certificate, and select the file from Downloads. Complete Android’s confirmation to install.
  3. Return to Ubuntu. Scan the separate private pairing QR and open it in Firefox. After approval, use the Firefox menu to Add to Home screen or follow the Install prompt if offered.

Use the certificate export in Project Chat on Ubuntu if the setup download is unavailable.
